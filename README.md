# BookTok
App for book lovers and new content seekers inspired by TikTok.

![BookTok](https://github.com/user-attachments/assets/af8d0d11-5b6a-4090-ba08-dbe06a9f179c)

### Architecture
The app is build on top of the **Google Books API**. It implements custom randomization algorithm based on such characteristics:
- first letter
- page
- offset

Liked books are maintained with **Core Data**.

Designed by the **MVVM architecture**:
- Separation of Concerns
- Data Binding
- Improved Testability
